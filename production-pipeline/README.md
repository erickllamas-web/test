# production-pipeline

The film pipeline above the renderer: tables (the film language), a strategy compiler that writes the shot file, the
editor that cuts by rule and tests the cut, the finish (sound, titles, master), frame identity and a render queue,
and the archive. Start with `MANUAL.md`; the design and the measurements that led to it are in
`PIPELINE_v3_thinking.md`; the tables are readable in `film-language/FILM_LANGUAGE.md`.
